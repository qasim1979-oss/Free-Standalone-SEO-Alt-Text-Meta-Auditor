# Free Standalone SEO Alt-Text & Meta Auditor (.exe)

A fast, multi-threaded, 100% offline Windows desktop application designed to audit local HTML site exports, website backups, and web project directories for technical SEO gaps.

Developed by **Muhammad Qasim Aziz** | **[HITS Web SEO Write](https://webseowrite.pk)**

---

## 🚀 Key Features
- **Multi-Threaded Performance:** Audit hundreds of HTML files in seconds with zero GUI freezes.
- **Image Alt Text Auditing:** Identifies all images lacking `alt` attributes across your pages.
- **Meta & Title Verification:** Detects missing or empty `<title>` tags and meta descriptions.
- **Smart Directory Exclusion:** Automatically ignores non-essential developer subfolders (`node_modules`, `vendor`, `.git`, `cache`).
- **CSV Report Generator:** Generates a structured `.csv` audit file with a single click.

---

## 📥 How to Download & Run
1. Navigate to the **[Releases](../../releases)** section on the right sidebar.
2. Download `seo_auditor.exe`.
3. Launch the app, select your website root folder, and click **Run SEO Audit Now**.
4. Click **Export Full Report to CSV** to save your structured audit results!
